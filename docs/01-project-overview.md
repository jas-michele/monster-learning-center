# Monster Learning Center

Mission

Create an educational platform that feels like playing with a favorite toy instead of doing homework.

Children don't learn by interacting with software. They learn by interacting with characters. AI allows those characters to finally listen, respond, encourage, and adapt to each individual child.

Audience

Ages 2-8

Platform

Desktop
Touchscreen
Raspberry Pi
Future Tablet

Core Philosophy

Play First.
Learning Second.
Rewards Always.

Learning Areas

Alphabet
Numbers
Colors
Shapes
Reading
Problem Solving
Memory
Critical Thinking
